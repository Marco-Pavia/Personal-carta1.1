💌 Una carta para Valeria ❤️

Una pequeña experiencia digital creada con mucho cariño para una persona especial. Una carta romántica e interactiva que se descubre al abrir un sobre animado, convirtiendo unas simples palabras en un detalle inolvidable.

✨ Sobre el proyecto

Una carta para Valeria es una página web diseñada para transmitir cariño mediante una experiencia visual delicada, romántica y especial.

Al ingresar, encontrarás una pequeña introducción acompañada de un sobre interactivo. Al hacer clic sobre él, se revela una carta con un mensaje dedicado especialmente a Valeria.

🌷 Características
💌 Sobre interactivo con animación de apertura.
❤️ Fondo decorativo con corazones.
✨ Diseño romántico y elegante.
📜 Carta con animaciones y detalles visuales.
💗 Ventana emergente para visualizar el mensaje.
📱 Diseño adaptable a dispositivos móviles.
🎨 Tipografías elegantes de Google Fonts.
🛠️ Tecnologías utilizadas
HTML5: estructura y contenido de la página.
CSS3: estilos, animaciones y diseño visual.
JavaScript: interactividad y funcionamiento de la carta.
Google Fonts: tipografías DM Sans, Great Vibes y Playfair Display.
